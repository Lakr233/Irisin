# Strong imports the iOS 15.0 floor allows although no SDK header declares them.
# Scripts/check-floor-imports.py reads this for the app, irisind and
# irisin-install. Everything down to the Irisin section is icli's own list
# (scripts/floor-imports.txt there), since irisin-install links IcliKit.
#
# The linker resolves every symbol against the newest SDK's .tbd files, which
# export what later systems added, and dyld refuses a binary at launch when a
# strong import is missing from the running OS: xpc_user_sessions_get_foreground_uid
# (iOS 16) shipped that way and stopped Xrash on iOS 15.8.6. SDK-declared APIs
# are covered by building at the 15.0 triple, which weak-links anything newer;
# a private symbol has no availability, so it is listed here only once it is
# known to be exported by iOS 15.0. Anything later is resolved with dlsym.
