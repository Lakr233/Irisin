Irisin Manual

The Irisin Manual.

Irisin is a package manager for an iPhone or iPad that runs custom firmware, on iOS or iPadOS 16 or later, with a roothide or a rootless bootstrap. You add repositories, find packages in them, review every change in a queue before it runs, and see what happened when one fails. This manual covers each of those in the order you meet them.

If you are deciding whether to install Irisin, or which of its two packages is yours, begin with Installing Irisin. If you are stuck, start at chapter 8, When Something Fails. It opens with a list of symptoms and covers a failed install, the wrong package, compatibility mode, and the logs you attach to a report. A name styled like Execute is quoted from the app, spelled exactly as it appears on screen.
