Irisin 5.0.2 puts Irisin on the Apple TV's Home Screen, managed from a browser. Nothing on screen changes on iPhone and iPad.

- **Irisin on Apple TV.** The Apple TV package (RootHide, `appletvos-arm64e`) now carries an Irisin app beside the daemon and the installer. It shows one screen: the address of a page, a six-digit code and a QR code of both. Open the page on a phone or computer on the same network to browse repositories, search, install and remove packages, and see what is installed.
- **The owner says yes on the TV.** Every change a browser asks for, adding or deleting a repository, installing or removing packages, is put to whoever holds the remote first, with Decline focused and Menu declining. A paid package does not install from a browser.
- **Apple TV starts with OwnGoal's repository.** On its first launch with no repositories, Irisin on Apple TV adds `https://apt.owngoal.dev`, the one repository that publishes Apple TV packages so far.
- **More on the page.** The browser page gains a Device view with storage and Clear Downloads, and the repository list can be exported and imported (addresses only, each import put to the owner).

Tested on an Apple TV 4K (tvOS 26.6, RootHide) and in the tvOS simulator: browsing, searching, the installed list, storage, export, adding and deleting repositories, declining and confirming from the remote, a wrong code refused, and a full install of Irisin through the page. The Apple TV HD and tvOS 17 were not tested. On iPhone and iPad the app's shared code moved but does as it did; it was built and checked by CI, not tested on a device.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware on iPhone and iPad, and `appletvos-arm64e` for RootHide on Apple TV. SHA-256 checksums are included in `SHA256SUMS`.
