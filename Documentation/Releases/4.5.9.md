Irisin 4.5.9 lets you queue an installation while packages download, and helps set up a system with no bootstrap.

- **Queue Install.** While packages are still downloading, the queue's button reads Queue Install. Tap it and the installation starts as soon as every file is here. The button turns red and reads Cancel Auto Install until then; tap it again to take the installation back.
- **No dpkg yet.** On a system where dpkg is not installed, Execute asks first: Bootstrap Install, Install Anyway or Cancel. Install Anyway names the packages that run maintainer scripts, which are likely to fail without a bootstrap, before anything is installed.
- **Updating Irisin without a bootstrap.** When Irisin updates itself, a failure of its own configuration or removal scripts no longer stops the update, and the installer starts Irisin's background service itself at the end. This applies from the next update after 4.5.9, which is installed by 4.5.9's installer.
- **Where packages came from.** The Installed page names each package's repository, or External, and follows a repository that is renamed or removed.
- **Search** shows each package's version after its name.
- **Settings → Repositories.** Auto Refresh sets how often Irisin refreshes your repositories on its own: Off, Every Hour, Every 6 Hours or Every Day. Clean Up Repositories has moved here from Packages.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
