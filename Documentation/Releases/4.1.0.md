Irisin 4.1.0 — packages are recorded exactly as dpkg records them.

- A tweak that checks its own installation no longer reports a modified or
  unofficial copy after Irisin installed it. Irisin now writes what dpkg
  writes beside the files: the `md5sums` of a package that ships none, the
  `/.` entry at the head of its file list, and fields such as
  `SileoDepiction` spelled and ordered as the package wrote them. The
  installed files themselves were always identical. Reinstall a package
  that complained; one installed by an earlier version keeps its old
  records until then.
- Package icons no longer blink when you come back to the app, while a
  repository refreshes, or as you type in search.
