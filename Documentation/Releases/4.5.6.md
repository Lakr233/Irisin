Irisin 4.5.6 stops the app freezing while your repositories refresh.

- The app no longer freezes for up to a second at a time during a refresh. The main thread used to save each repository to the package database, and waited whenever another repository was being written.
- Each repository refresh writes its packages faster. Search entries for a repository are now removed directly, without reading every other repository's entries first. After updating, each repository takes the old, slower path once, on its first refresh.
- The dashboard's Recent Updates section is built with one database read per repository instead of one per package.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
