Irisin 4.0.9 — BigBoss on rootless and roothide, and two iPad fixes.

- A repository with a suite (`deb … stable main`) that has nothing built for
  your jailbreak is now read from the index it does have. BigBoss, which
  publishes rootless packages only, refreshes on roothide and its packages
  install through Compatibility Mode. A repository with only rootful
  packages lists them and says they do not install here, where its refresh
  used to fail.
- BigBoss is among the repositories offered at first launch, and its icon
  is found.
- Package names and descriptions that a repository typed in an older
  encoding no longer turn the rest of its list into unreadable text.
- iPad: fixed a crash in package lists, and the first page no longer blinks
  in after the sidebar at launch.
