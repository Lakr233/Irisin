Irisin 4.5.12 starts SSH as soon as it is installed, and opens on iOS 26 and earlier when built with Xcode 27.

- **Services start on install.** A package that starts its service from `extrainst_`, as OpenSSH does, now has it running as soon as the install finishes. Before, sshd did not start until the next reboot.
- **Opens on iOS 26 and earlier.** A build made with Xcode 27 no longer quits at launch with “Symbol not found: _swift_initBorrow”.
- **A full disk no longer crashes Irisin.** When the disk is full, Irisin skips the log line it cannot write instead of quitting.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
