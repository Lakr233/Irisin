Irisin 4.7.2 offers to reload the home screen when an operation changes your tweaks.

- **Reload Home Screen when tweaks changed.** Tweaks load only when the home screen starts. When an operation adds, replaces or removes something in the tweak folder (`/Library/MobileSubstrate/DynamicLibraries` or `/usr/lib/TweakInject`), the button that closes the operation page reads Reload Home Screen. Touch and hold it for Skip for Now, which closes the page and leaves the home screen as it is. A failed operation that changed tweaks offers it too, and so does Try Again after one.
- **Everything else ends as before.** An operation that changes no tweak ends with the checkmark, and an update of Irisin itself still ends with the checkmark and closes the app, even when the same operation changed tweaks: reload the home screen from Settings once Irisin is open again.

Tested on iOS 26.6.2 with RootHide: installing, reinstalling and removing a tweak, an operation that changes no tweak, a failed operation and Try Again, Skip for Now, Reload Home Screen, and updating Irisin together with a tweak. iOS 27 and rootless firmware were not tested for this release.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
