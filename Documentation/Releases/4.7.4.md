Irisin 4.7.4 adds irisin-cli, Irisin's package manager for the shell, swipe actions on every package list, and marks on search results for what is installed.

- **irisin-cli.** Run `sudo irisin-cli` to search, show and list packages, install them by name, by version or from a `.deb` file with what they need, remove them, and install every update, as Irisin does. It reads the repositories Irisin keeps (refresh them in Irisin) and installs through Irisin's own service, so a transaction finishes even if irisin-cli is stopped. It also shows paid repositories' sign-ins and purchases, prints the device identifier, restarts the home screen, and answers the questions scripts ask with `dpkg-query` and `dpkg`. It runs only as root, and `--json` prints one JSON object per line for scripts. Irisin, if open, shows what irisin-cli installed or removed at once.
- **Swipe a package to act on it.** Swipe left on a package in the Dashboard, Installed, search results, a repository's sections or an author's list for Install, Update, Reinstall or Remove, on iPhone and in the iPad's columns alike. A change that needs nothing else joins the queue at once; one that brings other packages along shows them first.
- **Search shows what is installed.** A search result's icon carries a check when the package is installed, an arrow up when an update is offered, and an arrow down when the version shown is older than the one installed.
- **See what the queue will do.** A package in the queue carries an arrow on its icon in every list, or a cross when the queue removes it.
- **Search all repositories from Installed.** Searching the Installed page offers Search All Repositories under the list, even when nothing installed matches.
- **Authors by name.** An author written with an address or a link shows the name alone.
- **The queue bar stays above the keyboard** while you search.
- **Welcome Page starts from the beginning.** In 4.7.3, Settings › More › Welcome Page showed only the page about verifying ownership to anyone who had seen onboarding before. It shows every page again.

Installed over 4.7.3 and tested on iOS 26.6.2 and 27.0.1 with RootHide, in the iPhone and the iPad layout. irisin-cli: turned away without sudo; listing, searching, showing and listing updates; a dry run of every update; installing and removing a package; `dpkg-query`, `dpkg` and `--json`; updating Irisin from 4.7.3 to 4.7.4 itself, and installing Irisin again with the app open and with it closed, stopped partway once with Ctrl-C and once with SIGKILL, the transaction finishing either way. The app: the Welcome Page from Settings, the marks on search results, swiping in the Dashboard and in Installed in both layouts, a reinstall joining the queue from a swipe, its arrow, and leaving the queue again, and a package with dependencies showing them before it joins. The queue bar above the keyboard was not tested: the test devices show no on-screen keyboard. Rootless firmware was not tested for this release.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
