Irisin 4.3.10 lets custom firmware choose the repositories the welcome page recommends.

- The recommended repositories are no longer written into the app. Each package carries its own list — `default-list-iphoneos-arm64.plist` for rootless, `default-list-iphoneos-arm64e.plist` for RootHide — beside the app, and the welcome page reads it when it opens.
- `default-list-managed.plist` ships empty, with its format written in it. Custom firmware may overwrite it; when it lists any repository, the welcome page recommends that list in place of the package's own. An empty or unreadable file changes nothing.
- A copy of Irisin with no list for its bootstrap shows no recommended section, only Add More.
- Procursus's suite for each iOS release is now an entry in the rootless list, bounded by iOS version, rather than code.

Nothing else changed: the lists recommend the same repositories as 4.3.9, and the page looks the same.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
