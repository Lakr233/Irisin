Irisin 5.1.8 moves to icli 1.0.0, the library its installer uses to tell the home screen about apps and to manage its own daemon.

- **icli 1.0.0.** Up from 0.10.0. The versions between add a device passcode unlock (0.11.0) and an interface geometry API for library callers (1.0.0); Irisin uses neither. What Irisin calls, registering and unregistering apps, respringing and starting its own daemon, is unchanged. (#150)

Nothing else changed: no interface and no behaviour.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware on iPhone and iPad, and `appletvos-arm64e` for RootHide on Apple TV. SHA-256 checksums are included in `SHA256SUMS`.
