Irisin 4.5.0 refreshes a long list of repositories faster, and shows the queue almost at once when you tap Install.

- A repository whose server stops answering no longer holds up the others. After 8 seconds of silence it makes way for the next repository, and after 25 it is given up and keeps the packages it already had. With 111 repositories, nine in ten are refreshed within 20 seconds instead of 35 to 45, and a server that never answers costs 20 seconds instead of two minutes.
- The next repository starts as soon as one finishes, and those that were slow or failed last time go last.
- A repository that has packages but ran into trouble on its last refresh shows an orange dot instead of a red one, and its page says what went wrong: the server could not be reached, stopped responding or returned an error, it has no package list for this device, or its Release file cannot be read. Red now means a repository has no packages at all.
- A repository whose Release file lists its checksums more than once, such as mtac.app, now shows its name.
- Tapping Install works out what to install about ten times faster with many repositories: Irisin reads the package catalogue ahead, in the background, once your packages stop changing.
- The queue no longer lists packages from other repositories whose requirements cannot be read. It mentions only the packages your change involves.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
