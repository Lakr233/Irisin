Irisin 4.2.1 — a package page that says when it is translating.

- With Auto Translate on, a line under a package's name says Translating…
  while the page is with the translator, then that the page is translated,
  or that it could not be. With it off, a translation chosen from the menu
  waits behind a progress alert that can cancel it.
- A package page no longer slides into place while it opens, and a long
  package name is shown whole, over as many lines as it needs.
- A package installed in compatibility mode stays at its version: a newer
  one that would have to be converted again is left out of Updates, the
  badge and an update of everything, until Compatibility Updates is turned
  on in Settings. Asked for by name it installs as before.
