Irisin 5.1.1 recommends one repository fewer on RootHide and keeps a refresh's log to what went wrong.

- **roothide's repository is no longer recommended.** On RootHide, the Welcome page recommends OwnGoal Stripe, which has the bootstrap's packages, and apt.owngoal.dev; `roothide.github.io` is no longer on the list. iOS 15 still gets roothide's build of Procursus, which Stripe does not build for. Repositories you have already added are left as they are, and `roothide.github.io` can still be added by hand.
- **A refresh no longer logs files it stopped asking for.** Irisin asks for every compressed copy of an index that the repository's Release lists at once, and reads the first to arrive. The others are stopped, and the log said each was "in the Release and could not be had", which read like a broken repository. They are no longer logged; a file the server does not have still is.

Tested with Irisin's own tests on the Mac and in the iOS simulator: a refresh from a server that answers with the uncompressed index while its compressed copies never arrive, one whose Release lists a file the server does not have, and the recommended lists for every iOS release from 15. Not tested on a device for this release.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware on iPhone and iPad, and `appletvos-arm64e` for RootHide on Apple TV. SHA-256 checksums are included in `SHA256SUMS`.
