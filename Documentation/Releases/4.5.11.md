Irisin 4.5.11 retries a failed Bootstrap Install as a Bootstrap Install.

- **Bootstrap Install, tried again.** When a Bootstrap Install fails, Try Again runs it as a Bootstrap Install again: the files of the packages it has not installed yet are placed before any script runs, and the packages the failed attempt left unfinished are set up with them. Before, Try Again ran a normal installation, whose scripts could fail for want of the files a Bootstrap Install places first.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
