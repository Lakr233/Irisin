Irisin 4.5.17 changes nothing you will see. It updates Swift Collections, a library Irisin is built with, to 1.7.1.

- **Swift Collections 1.7.1.** Irisin 4.5.12 stayed on an older version of this library because the newer one stopped Irisin from opening on iOS 26 and earlier. Version 1.7.1 fixes that, so Irisin moves to it, and every package is still checked to open on its oldest supported iOS before it is published.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
