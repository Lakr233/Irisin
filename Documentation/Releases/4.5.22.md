Irisin 4.5.22 fixes Update All while repositories refresh, and is built with icli 0.7.16.

- **Update All finds every update during a refresh.** Tapping Update All while repositories were still refreshing could show "No changes" even though the Updates page listed updates. It now checks the same packages the Updates page shows.
- **icli 0.7.16.** The library Irisin installs packages with now reads and sets the system time zone.
- **AlertController 3.0.0.** The library behind Irisin's alerts is updated.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
