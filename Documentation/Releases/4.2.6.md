Irisin 4.2.6 — a repository that offers a package for more than one
bootstrap is read whole.

- On roothide a suite repository's `binary-iphoneos-arm64e` and
  `binary-iphoneos-arm64` directories are read as one catalogue, so a
  repository with a few packages built for roothide and the rest for
  rootless offers them all. A directory the server does not have as its
  Release lists it no longer takes the other down with it.
- Where one repository lists the same package for several
  architectures, each version keeps the build that fits the device
  best: its own, then `all`, then one that installs in compatibility
  mode. A build nothing here installs is listed only for a package with
  no other.
- A version built for the device is offered as the update ahead of a
  newer one that would install in compatibility mode, on the Updates
  page and in a list's update arrow alike, as the queue already picked
  it; the newer one is never an update with Compatibility Updates off.
  Selecting it by hand still recommends the older version built for the
  device.
- A package whose `Architecture` field names several is installable
  when one of them is the device's.
