Irisin 4.2.9 improves recovery actions and failed installation results.

- Failed operations show package results directly, with Try Again below the list.
- Ignore Script Errors and Retry now starts a new attempt immediately after confirmation.
- Failed single-package requests can offer recovery removal for an installed package, while retaining held-package and system-package protection.
- Recovery attempts identify the selected package as requested, rather than as a dependency.
- Installation-stage labels now describe installation instead of incorrectly reporting every failure as unpacking. Updated all translations.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
