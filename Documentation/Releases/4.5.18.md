Irisin 4.5.18 changes nothing you will see. Every package is now checked before it is published for the graphics access Irisin needs.

- **Graphics access is checked.** iOS draws Bold Text, app icons and the share sheet with the graphics processor, and an app without access to it closes when it does. Irisin has had that access since 4.0.2; a build that loses any of it is now refused before it is published, and the other OwnGoal apps carry the same check.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
