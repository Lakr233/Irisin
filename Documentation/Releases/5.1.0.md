Irisin 5.1.0 updates dpkg itself again, recommends OwnGoal Stripe on RootHide and Apple TV, and runs on Apple TV from tvOS 16.

- **Updating dpkg no longer stops at "Package data cannot overwrite the package database".** dpkg's own package carries the folders where the list of installed packages is kept. When its update also dropped files the old version had, as dpkg 1.21.21 to 1.22.6 does, Irisin took those folders for files written over that list and stopped. It now updates dpkg as `dpkg -i` does and leaves the list where it is. Other packages install as before.
- **OwnGoal Stripe is recommended on RootHide.** On iOS 16 and later, the Welcome page recommends OwnGoal Stripe (`stripe.owngoal.dev`, suite 1900) for the base packages such as dpkg and apt, in place of roothide's Procursus build. iOS 15 keeps roothide's, which Stripe does not build for.
- **Apple TV from tvOS 16.** Irisin on Apple TV now runs on tvOS 16 and later, as OwnGoal Stripe's packages for Apple TV do; it needed tvOS 17 before. On its first launch it adds OwnGoal Stripe beside apt.owngoal.dev.

Repositories you have already added are left as they are; add `https://stripe.owngoal.dev` with suite `1900` and component `main` to use it now.

Tested on iPhone with RootHide, iOS 26.4 and 27.0.1, with the fix built onto 5.0.4: a package laid out as dpkg's own, carrying the folders of the list of installed packages and dropping a file in its update, stopped 5.0.4 at the same error, and with the fix it updated, the dropped file gone and the list where it was; the device's own `dpkg -i` and `dpkg -r` left the same state. A plain package installed and removed, and Irisin opened. In the Apple TV simulator, built for tvOS 16, the first launch added OwnGoal Stripe and apt.owngoal.dev and read Stripe's packages. iPad, rootless firmware and Apple TV hardware, tvOS 16 and 17 among it, were not tested for this release.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware on iPhone and iPad, and `appletvos-arm64e` for RootHide on Apple TV. SHA-256 checksums are included in `SHA256SUMS`.
