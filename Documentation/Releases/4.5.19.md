Irisin 4.5.19 changes nothing you will see. It is built with icli 0.7.14.

- **icli 0.7.14.** The library Irisin uses for the home screen and its own daemon now keeps a long-running caller's memory bounded, writes every value it reports as valid JSON, and registers the extensions of apps installed into their own containers. Nothing Irisin does changes with it.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
