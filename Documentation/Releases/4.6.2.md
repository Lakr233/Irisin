Irisin 4.6.2 finishes installs that touch apps sooner.

- **Only the apps that changed.** After installing or removing packages, Irisin registers or unregisters only the apps those packages changed, instead of checking every app in the Applications folder. An app that a package's script creates or rewrites is still registered. Rebuild Icon Cache in Settings still checks every app. Tested on iOS 15.8.6 with a rootless bootstrap.
- **icli 0.8.4.** The library Irisin uses to register apps now looks up only the apps it is working on, instead of reading every app on the device each time.
- **Cloud storage.** Irisin can now read and write iCloud Drive and other cloud storage folders.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
