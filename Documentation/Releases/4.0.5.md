Irisin 4.0.5 — no update badge for a package that cannot install.

- A package list marked an installed package as having an update when a
  repository offered a newer build for the other jailbreak, such as a
  roothide build on a rootless device, though the update check correctly
  found nothing to install. A build this device cannot install, as built or
  through Irisin's conversion, now gets no badge at all.

| Jailbreak | Package |
| --- | --- |
| roothide | `wiki.qaq.irisin_4.0.5_iphoneos-arm64e.deb` |
| rootless (`/var/jb`) | `wiki.qaq.irisin_4.0.5_iphoneos-arm64.deb` |

Update from inside Irisin, or install by hand:

```sh
sudo dpkg -i <package>.deb
```

SHA-256 sums are in `SHA256SUMS`.
