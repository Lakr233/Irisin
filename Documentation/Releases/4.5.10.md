Irisin 4.5.10 opens packages shared from iCloud Drive.

- **Packages in iCloud Drive.** A `.deb` shared to Irisin from iCloud Drive in the Files app no longer fails with “This package could not be verified”. Irisin waits for the file to download, then opens it. Leave the page to stop the download.
- **Repository lists in iCloud Drive.** A `.irisinrepos` or `.irisinrepo` file opened from iCloud Drive is read the same way.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
