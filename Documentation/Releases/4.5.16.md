Irisin 4.5.16 adds a search bar to the Repositories page.

- **Search repositories.** Type in the search bar at the top of the Repositories page to show only the repositories whose name, description or address contains the text. When nothing matches, the page says so.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
