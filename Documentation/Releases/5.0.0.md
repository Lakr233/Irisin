Irisin 5.0.0 lists only what your system can install, and no longer converts packages built for the other bootstrap.

- **Compatibility Mode is gone.** On RootHide, Irisin no longer converts rootless packages before installing them. The Patch step on the Queue page, the Compatibility Mode warning and the Compatibility Updates switch in Settings are gone with it, and Irisin is smaller for it.
- **Only packages for your system are listed.** Repositories, search, updates and package pages show packages built for this device, plus the ones built for every system. A repository that publishes nothing for your device refreshes without an error and lists no packages, and Clean Up Repositories leaves it alone. Packages from the other bootstrap that a repository listed before this update disappear once that repository refreshes.
- **A package for the other bootstrap says so.** A package file you open, or an installed package, that is built for the other bootstrap shows Unsupported. Tapping it explains why and suggests rebuilding it for this device with Apelin.
- **Fewer recommended repositories on RootHide.** The welcome page no longer recommends Havoc, Chariz and BigBoss on RootHide, since they publish no RootHide packages. The rootless list is unchanged.
- **Numbers roll when they change.** Download percentages in the queue, values in Settings and the counts in the iPad sidebar roll from one value to the next.

Installed over 4.7.5 with irisin-cli and tested on iOS 26.4 and 27.0.1 with RootHide, in the iPhone and the iPad layout: the update of Irisin itself, Irisin registering its new build, the Dashboard, Settings, installing and removing a command-line package, a repository with no RootHide packages refreshing as empty, and opening a rootless package file. Rootless firmware was not tested for this release.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
