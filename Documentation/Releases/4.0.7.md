Irisin 4.0.7 — rootless packages on roothide, converted as RootHidePatcher converts them.

- Compatibility Mode now converts what roothide's own patcher converts:
  command-line programs, apps, launch daemons, libSandy profiles and hard
  links, not only tweaks. A converted package is the same, file for file,
  as the one `patch.sh` makes; what it would make otherwise is refused
  with the reason, never installed half converted.
- Installing a `.deb` you opened in Irisin works again, and a package you
  chose yourself stays chosen when the queue is worked out.
- Package paths are checked byte by byte on their way to the installer, so
  an unusual file name inside a package can no longer slip past the checks
  that keep it inside the jailbreak.

| Jailbreak | Package |
| --- | --- |
| roothide | `wiki.qaq.irisin_4.0.7_iphoneos-arm64e.deb` |
| rootless (`/var/jb`) | `wiki.qaq.irisin_4.0.7_iphoneos-arm64.deb` |

Update from inside Irisin, or install by hand:

```sh
sudo dpkg -i <package>.deb
```

SHA-256 sums are in `SHA256SUMS`.
