Irisin 4.2.8 improves package recovery, installation diagnostics, and background service management.

- Added recovery-mode installation and recovery for package configuration errors.
- Package resolution failures now explain why the requested changes could not be resolved.
- Improved operation warning banners and local version selection.
- Updated IcliKit to 0.4.1. Irisin now manages its background service directly, without a launchctl package dependency.
- Fixed background service executable paths on RootHide. The daemon exits when its executable is replaced or removed, while an in-progress installation can finish independently.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
