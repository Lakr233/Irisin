Irisin 5.1.5 lets `irisin-cli` install a set of packages from repositories you name on the command line. This works on a new bootstrap before Irisin has ever been opened, so a setup script can use it.

- **`irisin-cli install --repository <source>`** resolves the install against the repositories you give it. Give each one as its address or as `deb <url> <suite> <components>`, and repeat the option for more than one. `irisin-cli` refreshes them right away into a temporary catalogue owned by root and deletes that catalogue when the command ends. It does not read or change Irisin's own catalogue, so the app does not need to have been opened or to have any repositories added. (#147)
- **`irisin-cli install --bootstrap-install`** places every package's files before any maintainer script runs, like Bootstrap Install in the app. The scripts of a first installation can then use the shell and tools that the same run installs. Without it, a package set such as `owngoal-bootstrap-vphone` stopped at `openssh-server`, whose script ran before `dash` and `launchctl` were in place. As in the app, it is refused when the plan would reinstall a package that is already installed or remove anything. (#147)

`Documentation/CommandLine.md` describes both options. The app itself has not changed.

Tested on RootHide in virtual machines, iPhone on iOS 26.4 and iPad on iOS 27.0.1, with the CI package installed over Irisin 5.0.4 and 5.1.1. On both, a dry run of `install --repository https://apt.owngoal.dev` refreshed the repository's 44 packages and planned the install, in plain text and in `--json`. A package that the repository does not offer, and an address that does not answer, were refused with a message. `--bootstrap-install` was refused for a package that was already installed. A real install of `com.opa334.altlist` with `--bootstrap-install` and a `deb` line ran as a Bootstrap Install and left the package `ii`. No catalogue was left in a temporary folder, and the app's own catalogue was not touched; on the iPad, where Irisin had not built a catalogue yet, the command worked all the same. The app launched afterwards on both. The contributor also installed `owngoal-bootstrap-vphone` (90 packages) on a new iOS 27.0.1 bootstrap with these options, and `sshd` was running afterwards. Rootless firmware and Apple TV were not tested on a device for this release.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware on iPhone and iPad, and `appletvos-arm64e` for RootHide on Apple TV. SHA-256 checksums are included in `SHA256SUMS`.
