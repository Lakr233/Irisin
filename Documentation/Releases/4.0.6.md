Irisin 4.0.6 — lists that open in place and line up.

- Updates opens with its list already there instead of sliding the rows in
  while the page arrives. The log viewer no longer waits for a long log to
  be read before it opens.
- Installed and Search line up with the rest of the app: icons and section
  headers start at the same edge as on the Dashboard and in Repositories.
- The Installed author filter shows each author by name, without the email
  address or link after it, as the package page does.
- Section names read with spaces, not underscores (Terminal Support), in
  the Installed filter, a repository's sections and a package's details.
