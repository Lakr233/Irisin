Irisin 4.5.24 fixes a crash when the system runs low on memory, and shows text selection the way iOS does.

- **No crash under memory pressure.** After reading package descriptions with inline code or formulas, Irisin could quit when iOS asked apps to free memory. It now lets go of those descriptions safely.
- **Native text selection.** On iOS 17 and later, selecting text in a package's description shows the system's own highlight, handles and magnifier.
- **Text engine updated.** Package descriptions use Litext 3.6.3.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
