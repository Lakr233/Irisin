Irisin 4.5.25 adds a fallback for RootHide setups that have no home folder for Irisin.

- **Repairs a missing home folder, and only that.** Where the RootHide environment had no home folder for Irisin, Irisin quit right after launch. It now asks its background service to create the folder, then opens as usual. A normal RootHide or rootless installation already has this folder, never reaches the fallback, and sees no change.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
