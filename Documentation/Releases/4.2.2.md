Irisin 4.2.2 — a better package is pointed out before it is queued.

- Before a package joins the queue, Irisin looks at what else your
  repositories offer under the same identifier. If the one you selected
  would be installed in compatibility mode and another is built for this
  system, or a newer version of it exists, an alert says so: Select
  Recommended opens that package's page, Install Anyway goes on as asked.
  A downgrade is not told about newer versions.
- A repository refresh holds each package index to the Release fetched
  beside it. A stale index a CDN serves next to a current Release is
  refused and another spelling of it is tried, so an update that was
  published is an update you are offered.
- A translation chosen from a package page's menu can always be cancelled,
  on a card whose Cancel is there to tap, and the package's name is
  translated with the page.
- Add All, over the sources read from the clipboard, a link or a file, and
  over Recommended Repositories in onboarding, adds every one not added yet.
