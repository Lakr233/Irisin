Irisin 4.2.10 corrects recovery actions in the package diagnostic sheet.

- Recovery actions now appear as rows inside the scrolling table.
- Install and update requests offer recovery installation; removal requests offer recovery removal.
- Recovery removal uses the destructive action color.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
