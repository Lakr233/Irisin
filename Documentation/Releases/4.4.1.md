Irisin 4.4.1 is smaller again: the package falls from 5.7 MB to 4.9 MB, and installs in 17 MB instead of 21.

- The app, its daemon and its helper are built for size rather than speed. Nothing Irisin does waits on the difference: resolving dependencies and reading archives are done by libraries that were already built this way.
- The programs no longer carry a table of every name inside them, which only matters to code that links against them, and nothing does.
- The app links only the collection types it uses.

Nothing else changed: the interface, its wording and the way packages install are as they were in 4.4.0.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
