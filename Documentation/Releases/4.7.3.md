Irisin 4.7.3 can verify that you own the device before it changes packages, and gets test builds from GitHub.

- **Verify ownership before changes.** Irisin asks for Face ID, Touch ID or your passcode before it installs or removes packages: when you execute the queue, when you try again after a failure, and for a recovery install or removal. It is on unless you turn it off. A new onboarding page offers it, shown once to everyone who saw onboarding before, and Settings › Require Face ID turns it on or off after the same check. A device with no passcode is not asked.
- **Other tools must ask as root.** Irisin's background service now serves another installed tool only when that tool runs as root, as its own root service or a command run with sudo. Irisin's own app is served as before. Apelin already asks as root.
- **Get Test Update.** The More menu in Settings downloads the newest Irisin from GitHub, a pre-release included, and opens it as a package file handed to Irisin, ready to install from its page.
- **Settings › Packages** lists Blocked Updates first, then its switches.

Installed over 4.7.2 and tested on iOS 26.6.2 and 27.0.1 with RootHide, in the iPhone and the iPad layout: installing and removing a package from the app, Get Test Update, downgrading to 4.7.2 from within Irisin, the Settings order, a tool asking as mobile turned away and as root served, and Apelin installing and removing a package through Irisin. Verifying ownership was tested in the simulator with Face ID; neither test device has a passcode, and there Irisin asks for nothing and shows no page or switch for it. Rootless firmware was not tested for this release.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
