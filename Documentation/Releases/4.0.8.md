Irisin 4.0.8 — show the version change when opening a local package.

- A `.deb` opened from AirDrop or Files now offers Update when it is newer
  than the installed package, Reinstall when the versions match, and
  Downgrade when it is older. The action uses the file you opened.
- Blocking repository updates does not prevent updating from a local file
  you explicitly selected.

| Jailbreak | Package |
| --- | --- |
| roothide | `wiki.qaq.irisin_4.0.8_iphoneos-arm64e.deb` |
| rootless (`/var/jb`) | `wiki.qaq.irisin_4.0.8_iphoneos-arm64.deb` |

SHA-256 sums are in `SHA256SUMS`.
