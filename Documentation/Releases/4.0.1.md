Irisin 4.0.1 — the first release of the 4.0 rewrite.

An APT package manager for jailbroken iPhone and iPad on iOS/iPadOS 15 and
above. One binary serves both bootstraps: install the `iphoneos-arm64e`
package on roothide, the `iphoneos-arm64` one on rootless (`/var/jb`).

The app runs as `mobile` and never as root. The package ships a small
on-demand LaunchDaemon, `irisind`, which authenticates the app over XPC and
starts `irisin-install` for one job at a time. That helper installs packages
natively and registers app bundles with LaunchServices itself, in its own
session, so even an Irisin self-update runs to the end. No `dpkg` is spawned
and no `uicache` is needed.

| Jailbreak | Package |
| --- | --- |
| roothide | `wiki.qaq.irisin_4.0.1_iphoneos-arm64e.deb` |
| rootless (`/var/jb`) | `wiki.qaq.irisin_4.0.1_iphoneos-arm64.deb` |

```sh
sudo dpkg -i <package>.deb
```

SHA-256 sums are in `SHA256SUMS`.
