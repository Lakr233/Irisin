Irisin 4.0.3 — a rootless theme installs on roothide without the compat layer.

- On roothide, Irisin converts a rootless package the way roothide's own
  patcher does, and the patcher gives every package `rootless-compat` and,
  behind it, `com.roothide.patchloader`. Those are there for code. A package
  with no Mach-O in it (a theme, a set of icons) now gets neither: once its
  file is downloaded Irisin looks inside, and the two leave the queue before
  it runs. A tweak still gets both, as before.

| Jailbreak | Package |
| --- | --- |
| roothide | `wiki.qaq.irisin_4.0.3_iphoneos-arm64e.deb` |
| rootless (`/var/jb`) | `wiki.qaq.irisin_4.0.3_iphoneos-arm64.deb` |

Update from inside Irisin, or install by hand:

```sh
sudo dpkg -i <package>.deb
```

SHA-256 sums are in `SHA256SUMS`.
