Irisin 4.3.6 keeps installing after RootHide is jailbroken again.

- RootHide gives the bootstrap a new folder name at every jailbreak and rewrites each background service's path to match. Irisin's was rewritten wrongly, so its service never started again and every install stayed at Waiting. The service now survives the rename.
- A device already stuck at Waiting is repaired by installing this package once, from a terminal (`dpkg -i`) or another package manager.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
