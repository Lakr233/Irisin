Irisin 5.1.2 lets Update All through when an update needs a package from another repository, and says why when it cannot.

- **A package whose repository is gone updates from any repository.** A package Irisin installed takes its updates only from the repository it was installed from. If you removed that repository, or it no longer lists the package, the package got no updates at all, and neither did any update that needs a newer version of it. On RootHide, after moving from roothide's Procursus to OwnGoal Stripe, this held back apt, essential and dozens more behind roothide, and Update All showed only "No changes". Such a package is now offered updates from any repository, like one installed another way.
- **Migrate and Update.** When the repository is still there but an update needs a newer version that only another repository has, Update All lists the package under Needs Another Repository. It names both repositories and the updates that need it. Migrate and Update shows the plan with that package installed from the other repository, and from then on its updates come from there. Only the packages the held-back updates need move; a newer copy of anything else in another repository is still not an update.
- **Update All says what it held back.** When nothing else changed, the sheet used to drop its notes about held-back updates and show only "No changes". They are shown now.
- **`irisin-cli upgrade --migrate`.** `irisin-cli upgrade` names the packages that need another repository, and `--migrate` installs them from there with everything else.

Tested with Irisin's own tests on the Mac and in the iPad simulator, and on RootHide in virtual machines: iPhone on iOS 26.4 and 27.0.1, and iPad on iPadOS 27.0.1. Test repositories reproduced the report, with one package installed from a repository that was then removed, one from a repository that stays, and two updates that need newer versions of them from a third. On 5.1.1 those updates were held back without a reason. With the fix, on both iPhones the first package updated with Update All, the second moved through Migrate and Update, and everything installed; `irisin-cli upgrade` showed the same plan. On the iPad the sheets were checked and nothing was installed. Rootless firmware and Apple TV were not tested on a device for this release.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware on iPhone and iPad, and `appletvos-arm64e` for RootHide on Apple TV. SHA-256 checksums are included in `SHA256SUMS`.
