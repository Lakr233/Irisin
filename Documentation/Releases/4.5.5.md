Irisin 4.5.5 keeps package lists smooth while your repositories refresh.

- Package lists no longer stutter as you scroll, on iPad and iPhone alike: installed versions and where each package came from are kept in memory, and rows no longer wait on the package database.
- Search results appear right away and fill in their icon and description a moment later, instead of holding up the list.
- Refreshing many repositories no longer keeps the app busy recording package changes after each one; it does so once, after the last.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
