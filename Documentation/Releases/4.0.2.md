Irisin 4.0.2 — the app gets the GPU, and the installer gets every protected folder.

- The app no longer crashes with Bold Text turned on. A bootstrap keeps the
  GPU from an ad-hoc signed app until the app's entitlements name the GPU
  classes, and Metal, Core Image and bold text rendering all ask for it. The
  app now names Apple's GPU, IOSurface, the framebuffer, JPEG decoding, the
  Neural Engine and the classes UIKit opens for input.
- `irisin-install` carries every data-vault storage class, so a package that
  places files in a folder iOS protects even from root (preferences,
  keychains, containers and the rest) installs instead of failing there.
