Irisin 4.3.2 says why a package was refused when its repository lists it wrongly.

- A package whose repository listing differs from the package file is refused with the reason: an alert names the package and the fields that differ, such as Conflicts or Replaces. It used to fail with "Unable to prepare the installation."
- The log names each field with what the repository listed and what the file says.
- Nothing is installed from such a package, as before. Refresh the repository, or ask its maintainer to correct the listing.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
