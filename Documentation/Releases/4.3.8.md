Irisin 4.3.8 is a VoiceOver release: the controls that had no name now have one, and the rows that read as a pile of fragments now read as a sentence.

- Every icon-only control says what it does. More, Share, Settings, Refresh, Add Repository, Clear, See All and Update reached VoiceOver as an unnamed button; so did the Add button on a repository candidate, the button covering a Settings row, and the one covering a featured banner or a sidebar card.
- A package row, a search result and a repository row are one stop each and read their lines joined, instead of one stop per line with the drawn separators spoken between them.
- A path row reads the whole path, not the last component its indent stood for.
- State that was only drawn is now spoken: the Updates item says when everything is up to date, a cleanup row says whether it is ticked or blocked, a queue row says its progress and whether it opens, a sidebar card says its count and whether it is the open one.
- Section headers and the welcome title announce themselves as headers, and the progress fill behind a repository row is no longer read as a thing of its own.
- Four rows carried a name VoiceOver could never reach — the queue and operation rows and the diagnostic report's recovery and requirement rows. They are reachable now, and a build gate refuses the next one.

Nothing about the interface changed: no layout, no wording, no control flow.
