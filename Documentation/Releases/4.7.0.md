Irisin 4.7.0 lets other installed tools install, remove and track packages through Irisin's background service.

- **Other tools can install through Irisin.** A developer tool on your device, such as Apelin, could only install what it built by calling the package tools behind Irisin's back. It can now hand Irisin a package file and follow the installation step by step, see how it ended after reconnecting, remove a package by name and respring, while Irisin keeps the same checks it applies to its own installs. Submitting the same installation twice installs it once.
- **Who may ask is decided by what is installed, not by name.** Irisin's service answers any program installed by a package on your device that is owned by the system and carries Irisin's client permission, instead of Irisin's own app alone. A program in a folder other accounts can change is still turned away.

Installed over 4.6.3 and tested on iOS 26.6.2 and 27.0.1 with RootHide: refreshing, installing, updating and removing from the app, and every operation another tool can ask for. Rootless firmware was not tested for this release.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
