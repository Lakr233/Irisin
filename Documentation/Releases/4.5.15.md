Irisin 4.5.15 opens packages whose file names use characters beyond ASCII, and updates icli, which it uses to register apps and load its own daemon, to 0.7.5.

- **Non-ASCII file names in packages.** A package with a file named like `What’s New é.txt` failed to open with "Pathname can't be converted from UTF-8 to current locale", and installing it could crash. Irisin now reads these names as UTF-8. icli 0.7.5 fixes the same problem in its own archive reading.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
