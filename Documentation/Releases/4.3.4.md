Irisin 4.3.4 opens on a device whose Documents folder belongs to root.

- Installing the package now makes Irisin's data folder, `/var/mobile/Documents/wiki.qaq.irisin`, and hands it to `mobile`. Where a bootstrap had left `/var/mobile/Documents` owned by root, Irisin could not make the folder itself and crashed at launch.
- If the folder still cannot be made, the crash report now gives the path and the reason.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
