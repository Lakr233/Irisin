Irisin 4.1.2 — compatibility mode is patched before it installs.

- A queue with a package in compatibility mode shows Patch in place of
  Execute. Patch converts the packages once their downloads finish, and
  Execute appears after that.
- A package with no code in it, such as a theme, no longer brings the
  compatibility layer with it. If patching changes the queue, an alert says
  what was removed or added before you execute.
- The sheet that adds a package in compatibility mode says the queue may
  change when it is patched.
