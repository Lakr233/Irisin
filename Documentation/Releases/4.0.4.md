Irisin 4.0.4 — a welcome on first launch, search in package lists, and a stricter bootstrap check.

- The first launch opens a short welcome: what Irisin does, a list of
  recommended repositories for your jailbreak with Add on each (Procursus for
  your iOS version, Havoc, Chariz, ElleKit on rootless, RootHide's own
  repositories on roothide), and a word of caution before you start. Settings
  has a new ⋯ menu to show it again, open Irisin's page in the Settings app,
  or report an issue on GitHub.
- Package lists, such as a repository's packages and Recent Updates, have a
  search bar that narrows the list by name, description or identifier.
  Exporting a list exports what the search shows.
- Irisin now tells rootless and roothide apart from what the bootstrap
  reports, not from how its path is spelled. Dopamine spells that path
  differently, and Irisin could take a rootless Dopamine device for roothide.
  An Irisin package built for the other bootstrap now stops at launch and
  says which one to install, and Irisin never converts itself.
- Irisin is now released under the MIT License, by OwnGoal Studio.

