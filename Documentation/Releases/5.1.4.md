Irisin 5.1.4 repairs what an install that stopped partway left behind, with the next change you make. The operation page also stops offering to hide a run that is quiet for a while.

- **The next change repairs a run that stopped partway.** When a run stops at one package, the packages before it keep their new versions, and a package that has not been updated yet can be left needing an old one. On RootHide, a run that stopped at build-essential left libapt-pkg6.0 2.9.4-3 beside apt 2.6.0-2, which needs libapt-pkg6.0 2.6.0-2. After that, every change but Update All was refused with "apt requires libapt-pkg6.0 (= 2.6.0-2)", even an update of Irisin alone. Now any change also repairs the installed packages: it installs a dependency the run never got to, or updates a package to the version that fits, and the sheet lists that with the rest. The repair never removes the broken package. When no repository offers a version that fits, the change is refused as before and the reason names the package. (#146)
- **No Hide button on the operation page.** After two minutes with no new line, the page showed Hide, which closed the page and left the run going behind it. A large package can take that long with nothing to report, so Hide appeared under runs that were fine. The page now stays open until the operation ends. To see what the installer is doing, choose View Full Log from the … menu.

If your device is in that state on Irisin 5.1.3, run Update All once. It updates the package that is behind, along with Irisin.

Tested with Irisin's own tests on the Mac and in the iPad simulator, and on RootHide in virtual machines: iPhone on iOS 26.4 and 27.0.1. On both, a test run that stopped partway left a library at 2.0 beside a tool that needs 1.0, the shape of the report. Irisin 5.1.3 refused an unrelated install, and an update of Irisin alone, with the message from the report, and Update All listed the tool's update. With 5.1.4, both requests listed the tool's update to 2.0 beside them. Installing a package from its page in the app updated the tool in the same run, and so did an update of Irisin alone. With no repository offering the tool's 2.0, 5.1.4 still refused the change and named the tool. Against six public repositories and an installed system of 113 packages, 66 requests were planned exactly as 5.1.3 plans them. Rootless firmware and Apple TV were not tested on a device for this release.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware on iPhone and iPad, and `appletvos-arm64e` for RootHide on Apple TV. SHA-256 checksums are included in `SHA256SUMS`.
