Irisin 4.5.26 stops leaving the Documents folder to root, so apps without a container can keep their data there again.

- **Gives Documents back to mobile.** On a RootHide setup that had no Documents folder, installing Irisin created that folder owned by root, and apps without a container could then keep nothing in it — iGhostVT, for one, wrote no log. Installing or updating Irisin now creates each missing folder for mobile, and a Documents folder left owned by root goes back to mobile.
- If Irisin cannot create its data folder at launch, it now asks its background service to prepare it whatever the reason, not only when the home folder is missing.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
