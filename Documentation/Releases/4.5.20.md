Irisin 4.5.20 draws code blocks and tables in package descriptions with a bar of their own, and is built with icli 0.7.15.

- **Code blocks and tables have a bar.** A code block or table in a package's description now has a title bar with Copy and Expand. Expand opens it in a sheet, where the menu copies it, saves it as a file or closes the sheet. The text engine behind descriptions is updated with it.
- **icli 0.7.15.** On RootHide, the library Irisin uses for its own daemon now loads the daemon's property list the way RootHide's launchctl would.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
