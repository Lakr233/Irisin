Irisin 4.5.8 adds Bootstrap Install for the first package installation on custom firmware.

On a fresh bootstrap, `bash` may require `debianutils` to be configured first, while a `debianutils` maintainer script needs `bash` to run. Add the packages to the queue, then long-press Execute and choose Bootstrap Install. Irisin places the files from every verified package in the queue before running the normal unpack, script and configuration stages. Dependency checks and script failures still apply.

Bootstrap Install is offered for a queue of new packages with no removals. Regular installations continue to use Execute.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
