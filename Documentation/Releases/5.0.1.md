Irisin 5.0.1 is a maintenance release: nothing on screen changes.

- **Programs start through one path.** irisind and irisin-install now start the installer and the tools it runs through a single function, ahead of Apple TV support. What they run is unchanged.
- **Updated icli.** icli 0.10.0, which Irisin installs packages and registers apps with.
- **The handwritten name is part of Irisin.** The name drawn for a package with no icon now comes from Irisin itself instead of a separate library. It looks the same.

Installed over 5.0.0 with irisin-cli and tested on iOS 27.0.1 with RootHide, in the iPhone layout: the update of Irisin itself, installing and removing a command-line package through the new helper, and opening Irisin. iOS 26.4, the iPad layout and rootless firmware were not tested for this release.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
