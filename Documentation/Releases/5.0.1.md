Irisin 5.0.1 brings Irisin's installer to Apple TV. Nothing on screen changes on iPhone and iPad.

- **Apple TV.** A package for RootHide on Apple TV, tvOS 17 and later, `appletvos-arm64e`. It carries Irisin's daemon and installer alone, for other programs to install packages through: there is no Irisin app on Apple TV yet.
- **Programs start through one path.** irisind and irisin-install now start the installer and the tools it runs through a single function, on iOS as on tvOS. What they run is unchanged.
- **Updated icli.** icli 0.10.0, which Irisin installs packages and registers apps with.
- **The handwritten name is part of Irisin.** The name drawn for a package with no icon now comes from Irisin itself instead of a separate library. It looks the same.

Installed over 5.0.0 with irisin-cli and tested on iOS 27.0.1 with RootHide, in the iPhone layout: the update of Irisin itself, installing and removing a command-line package through the new helper, and opening Irisin. iOS 26.4, the iPad layout and rootless firmware were not tested for this release. The Apple TV package was tested on tvOS 26.6 with a hand-made RootHide root, before its architecture was named; tvOS 17 was not tested.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware on iPhone and iPad, and `appletvos-arm64e` for RootHide on Apple TV. SHA-256 checksums are included in `SHA256SUMS`.
