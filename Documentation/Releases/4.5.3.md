Irisin 4.5.3 refreshes your repositories more smoothly and helps you remove the ones that stopped working.

- In Settings, Clean Up Repositories under Packages lists each repository whose last refresh left it with no packages, so you can delete them together. Every row starts checked, and Irisin asks before it deletes anything.
- On iPad, the sidebar no longer stutters during a refresh. Repository icons are prepared once at the size the sidebar shows them, and less work is done as each repository finishes.
- On iPad, the number next to Repositories counts up as repositories finish refreshing, such as 92/111. Afterward, the number of repositories with no packages appears in red after the total.
- After you add a repository, Add in the add-repository sheet changes to Done, so you can close the sheet in one tap.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
