Irisin 4.5.2 stops refreshing a repository as soon as you delete it.

- Deleting a repository while it refreshes cancels its download at once. It no longer takes a place in the queue that other repositories are waiting for, and it no longer counts toward the number left.
- A repository deleted and added again while its first refresh was still running now refreshes on its own. Before, the new one was skipped, and it could show what the deleted one had downloaded.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
