Irisin 4.3.1 adds a user manual and opens it from Settings.

- Settings has a User Manual row, under Support, above Report Issue. It opens the manual in your browser.
- The manual is new: eight chapters covering installing Irisin, repositories, finding and installing packages, updates, compatibility mode, translation, every Settings row, and what to do when an install fails. It reads at <https://lakr233.github.io/Irisin/manual/>.
- Every control the manual names is the name this app shows, and a check fails the build when the two drift apart.

Choose `iphoneos-arm64e` for RootHide or `iphoneos-arm64` for rootless firmware. SHA-256 checksums are included in `SHA256SUMS`.
