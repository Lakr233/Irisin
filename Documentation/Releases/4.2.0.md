Irisin 4.2.0 — a package page in your language.

- Auto Translate (Settings, off by default) shows a package page as it was
  written, then brings in the same page translated by the system's own
  translator. Text already in your language is left alone, and links and
  code are never changed. The switch turns on once the device has shown it
  can translate.
- A package page's menu has Translate: Original, Translated or Compared,
  which puts the translation under each piece, then the language to
  translate from and the one to translate to. Tab names are translated too,
  and a page opened again does not ask twice.
- A package page says the package's size after its version, and an
  architecture the device does not run is marked against the device's own,
  in red.
- Settings is arranged as Packages, Downloads, System and Support. Report
  Issue is under Support, beside View Logs.
- Irisin opens from a clean start every time: interface state saved by an
  earlier version is dropped before it can be restored.
